Loop9 Backend

Symfony 8 API for Steam-authenticated AI chat, quotas, moderation, and run telemetry.

Steam App ID 4982260 · Health check /readyz

Maintained documentation

  • ARCHITECTURE.md — layers and pipelines
  • API.md — endpoints and contracts
  • CONFIGURATION.md — environment variables
  • AI_PIPELINE.md — prompts, routing, moderation
  • SECURITY_AND_PRIVACY.md — auth and privacy
  • OPERATIONS.md — deploy and runbooks
  • DEVELOPMENT_AND_TESTING.md — local setup and tests

GitHub Pages for this folder is published manually via workflow_dispatch (not on every push to main).

API surface

  • POST /api/auth/steam — Steam ticket → session token
  • POST /api/chat — preferred auth header X-Session-Token
  • POST /api/telemetry/run — anonymous run-finished telemetry
  • GET /healthz — liveness
  • GET /readyz — readiness
  • GET /privacy — public privacy policy

Legacy X-Game-Token auth is non-production only and rejected by readiness checks when APP_ENV=prod.
