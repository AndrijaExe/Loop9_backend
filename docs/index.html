Loop9 Backend

Symfony 8 API for game chat pipeline with rate limiting and AI provider fallback routing.

Deployment status: managed by GitHub Actions on push to main.

API Endpoint

POST /api/chat

  • Auth header: X-Game-Token
  • Quota key: player_id or X-Player-Id
  • Output format: game-ready assistant message payload

Runtime Notes

  • Global API error envelope via exception subscriber
  • CORS handling for /api/* routes
  • Provider ordering depends on loop_index
